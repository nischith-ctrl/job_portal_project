# CareerHub — Job Portal Web Application

A full-stack Job Portal built with **Python (Flask)**, **SQLite**, and **Bootstrap 5**.

## Features
- **3 User Roles:** Job Seekers, Employers, and Admin.
- **Job Search & Filters:** Filter jobs by keyword, location, category, and company.
- **Job Applications:** Seekers submit resume links and cover letters; Employers review applicants directly in their dashboard.
- **API Integration:** Public `/api/jobs` JSON endpoint + 1-click live job import from the Remotive API.
